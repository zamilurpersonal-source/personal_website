How the Lab works

The Lab loads RTR-test's own game code from this site (the build on the Prototypes page) and plays its battles with the graphics off, in workers that use your computer's processor cores. Nothing runs on Claude: it costs no Claude credit. Copy the report and paste it in your chat with Claude, who applies the changes and ships a new build; reload the Lab to test it.

Each battle has one knob, the enemy's strength. The auto-tuner tries values of it (60 games each, halving the range up to five times, then a curve through all of them) until the average player lands in the middle of their target, then checks every player at that value (90 games each). If one knob cannot bring all three inside their targets, the report says so: that needs a design change rather than a number.

Keep this window open and the computer awake (it can run overnight). In Chrome or Edge, the install icon in the address bar (or the menu: Cast, save and share → Install page as app) makes it a desktop app with its own window. Results are kept in this browser for the build you are testing; a new build starts fresh.
